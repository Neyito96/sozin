# SOZIN｜Square請求書 Free 導入・動作確認手順

更新：2026-11-12　Issue: https://github.com/Neyito96/sozin/issues/8

## 運用方針
- Square請求書 **Free** を第一候補にする。正式な制作仕様と税込金額を社長が承認してから請求書を送る。
- 銀行振込は継続する。
- `estimate/` の試算額は請求額として自動採用しない。
- `payment/` は案内ページにとどめ、お客様固有の決済URLや個人情報を公開コードに置かない。
- 決済サービスへの申込、口座認証、実際のカード決済・返金、運用開始は社長が実施・承認する。

## 1. 法人登録前に社長が用意する情報
- [ ] 事業用メールアドレス
- [ ] 会社の正式名称・所在地・電話番号・法人番号
- [ ] 登記上の代表取締役情報と事業内容（舞台公演プログラム、印刷物制作・デザイン等）
- [ ] 八十二長野銀行（旧八十二銀行）の法人名義口座情報。名義の正確な表記・合併後の銀行名/銀行コードを通帳・銀行サイトで照合
- [ ] 追加審査を求められた場合に備え、発行から6か月以内の登記簿謄本等
- [ ] 公式サイトURLと商品・サービスの説明、納品時期・キャンセル/返金規定

**注意：** 口座番号、本人確認書類、法人代表個人情報、ログイン情報をGitHub Issueや公開リポジトリに貼らない。追加資料が必要かはSquareの審査状況で変わる。

## 2. 登録手順（社長が操作）
1. https://squareup.com/signup にアクセス。
2. 国を日本として、事業用メールアドレス・パスワードで登録。
3. 事業形態は「法人/店舗」を選び、会社情報と代表者の情報を入力。
4. 登録する銀行口座の名義がSquare登録情報と一致するか確認。
5. 本人確認・加盟店審査の案内に従って提出。追加審査の書類を求められる場合がある。
6. 銀行口座の認証メール/ステータスを確認。通常、結果は3営業日以内に通知されるとSquareが案内。
7. 管理画面でSquare請求書の**フリー**プランであることを確認。

公式: https://squareup.com/help/jp/ja/article/5123-square-get-started-guide
公式: https://squareup.com/help/jp/ja/article/5682-account-on-boarding-assessment-faqs
公式: https://squareup.com/help/jp/ja/article/3896-link-and-edit-your-bank-account

## 3. 初期の請求書テンプレート
- 事業者名：創人デザインシステム株式会社（正式登記名を照合）
- 表示ブランド名：SOZIN Ballet de’ Arte
- 品目例：公演プログラム制作、印刷費、チラシ共通デザイン等
- 請求番号：社内管理台帳と一致する案件番号
- 明細：仕様・数量・単価、消費税、合計税込金額を確認
- 備考：納品・支払い条件、連絡先、キャンセル/返金条件
- 適格請求書発行事業者登録番号など、必要な記載事項は税理士/経理担当と照合

**登録完了前の操作試験：** Square管理画面の請求書作成で、社内テスト用の仮品目/金額を入れ「プレビュー」まで進む。**実在顧客へ送信しない**。最終送信前の画面で金額・税・決済手段・送信先を確認する。

公式: https://squareup.com/help/jp/ja/article/8387-create-and-send-invoices
公式: https://squareup.com/help/jp/ja/article/7893-customize-square-invoices

## 4. 運用開始前の試験計画
| 試験 | 期待結果 | 実施条件 |
| --- | --- | --- |
| 請求書プレビュー | 品名、税込合計、送信先、注意事項が正しい | アカウント設定後、無送信で可能 |
| 顧客向け表示 | スマホで金額・決済画面が読める | Squareの利用可能なプレビュー機能で確認 |
| カード決済の成否 | Square取引画面の決済状態と照合できる | Squareが提供する適切な試験手段を事前に確認し、代表承認後のみ |
| 返金 | 取引IDで返金処理・履歴を照合 | 実取引を伴う場合は代表承認後のみ |
| 二重払い | 案件番号と請求番号で重複を検出 | 運用ルールを決めて確認 |
| 口座入金 | Squareの決済情報と銀行入金明細が一致 | 有効化・実取引後 |
| 銀行振込併用 | 同じ案件にカード請求と振込で二重請求しない | 人間による承認フローを設定 |

**重要：** Square請求書の本番管理画面に、カード決済まで無料で模擬実行できる「テストモード」があると決めつけない。Square開発者向けSandboxは、本番請求書画面の無課金試験と同じではない。実際のカードによる少額決済には手数料や返金条件が発生し得るので、社長の明示承認がない限り実施しない。

## 5. 決済開始時のオペレーション
1. 社長が最終仕様・請求番号・税込金額を承認。
2. Square請求書を発行し、メール/SMSまたは共有リンクを顧客に送る。
3. 顧客はSquareのホスト型画面でカード/対応するウォレット等で支払う。
4. 社内の請求台帳にSquare決済ID・金額・日時を記録する。公開GitHubに書かない。
5. 入金済判定はSquareの決済状態を確認し、銀行入金と照合する。
6. 着手金/残金の分割、取消/返金は方針を明文化し、同一案件で二重請求をしない。

## 6. Squareの費用と入金
- 請求書 Free: 月額0円、請求書・見積書の作成と送信は無制限。
- 国内対象カードのSquare請求書決済手数料は通常3.25%。個別のカード種や支払い方法で異なる場合あり。最新の事業者プランと規約を確認。
- 八十二長野銀行はSquareの翌営業日振込対象（三井住友・みずほ）ではないため、通常は木曜〜翌水曜の売上を同週金曜日に振込。休日等の例外あり。
- 手数料例：税込100,000円の対象カード決済で3,250円、決済手数料控除後96,750円（他の調整項目なしの場合）。

公式: https://squareup.com/jp/ja/invoices/pricing
公式: https://squareup.com/help/jp/ja/article/5123-square-get-started-guide
