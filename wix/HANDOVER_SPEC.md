# SOZIN｜Wix自立運用型見積もりシステム 設計・引渡し仕様（ドラフト）

管理：[#19](https://github.com/Neyito96/sozin/issues/19)　作成日：2026-11-13

## ゴール
長年Wixを編集してきたSOZIN代表が、HTML・JavaScript・GitHubを操作することなく、商品情報から**基本料金、ページ単価、部数単価、オプション料金、税率**に至るまで変更できるようにする。開発者の継続的な貼り替え作業を前提としない。料金変更は公開前に確認でき、変更履歴・復元方法を用意する。

## 利用者別責務
- **SOZIN代表**：商品・説明・選択肢・税・価格表・公開設定・注意事項の変更、試算の検算、正式公開の承認
- **開発担当**：Wix CMSコレクション構造、Velo汎用計算エンジン、権限・例外処理、PDF/JPEG処理の保守。新しい計算方式が必要になったときのみ改修
- **顧客**：商品の仕様と合計参考額のみを閲覧。内部単価や算定式は見せない

## Wix標準UIとCMSモデル（提案）
| CMSコレクション | 代表が編集する項目例 | 権限 |
| --- | --- | --- |
| Products | 商品ID、表示名、説明、画像、表示順、公開状態 | 管理者編集・公開表示は必要な項目のみ |
| Options | 商品ID、選択肢ID、ラベル、最小/最大数量、初期値、適用状態 | 管理者編集・公開表示は必要な項目のみ |
| PriceRules | 商品ID、ルール種別（固定額/ページ課金/部数課金/区間別など）、金額、適用範囲、優先順位、有効開始/終了 | **非公開**：管理者編集のみ |
| SiteCopy | 見出し、リード、注意事項、問い合わせ案内、版表示 | 管理者編集・公開テキストのみ |
| ReleaseConfig | 公開版番号、設定セットID、有効日時、確認者、更新日 | 管理者のみ |

金額・計算式を秘密にするにはフロントエンドからPriceRulesを直接参照させず、Veloバックエンド経由で合計のみを返す。管理者の権限は確認が必要。

## 見積もり計算
1. 顧客の入力をサーバー側で検証（商品状態・数量範囲・選択可能な仕様）。
2. 公開中の設定セットを基に税込合計を算出。
3. 顧客側には商品名・入力した仕様・参考合計・注意事項のみ返却。
4. 料金未設定、矛盾する設定、無効な数量の場合は「個別見積もり」と表示。
5. 正式な請求・Square支払いリンクとは自動連動しない。社長の承認後に請求発行。

## 料金の更新と公開の流れ
1. 社長が管理画面の**下書き価格設定**を編集。
2. 変更前後の料金比較と代表的な境界値を自動計算し、入力ミスを警告。
3. 社長がPC/スマホ表示と価格を検算して公開を承認。
4. 公開版番号と日時を記録し、前版に戻せるようバックアップを保全。

Wix CMSのデータ編集とサイト全体の公開は同じ操作とは限らない。下書き・公開・復元の実際の仕様を当該Wix環境で検証してから手順を確定すること。

## 引渡しに必須の成果物
- 社長が編集する項目を説明した**スクリーンショット付き操作マニュアル**
- 最低10ケースの金額回帰テスト（各商品、最小・最大数量、区間境界、税、未設定）
- スマホおよびWixプレビューの操作確認、PDF・JPEGの試験記録
- 料金表CSVエクスポート/インポート、変更履歴と復元手順
- 社長が単独で商品追加・値上げ・公開停止・復元を実演する**受入試験**
- Wix CMS/Veloのプラン制限と追加費用の調査
- 社長のWixサイト所有権は維持。GitHubは設計書とソースの保全用で、普段の編集はWix内で完結

## 段階的実装
- Phase A：現行V0.5.1の機能・価格ルール・注意文の棚卸し
- Phase B：Products/SiteCopyのCMS化、Wix標準パーツで表示・入力を構築
- Phase C：PriceRules・Optionsの編集画面とVeloサーバー計算、テスト
- Phase D：PDF/JPEG、プレビュー・差分/復元、スマホ/Norton試験
- Phase E：社長の独立操作・承認後に旧埋め込みを退役

**現時点では設計のみ。** Wixの実サイト/CMSには未実装、設定変更や本番公開はしていない。
