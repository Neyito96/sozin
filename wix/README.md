# Wix埋め込み用 見積もりシミュレーター（試作）

Issue: https://github.com/Neyito96/sozin/issues/13

## コード
- `wix/estimate-test.html` — **1ファイルにHTML・JavaScriptを統合した版**
- 元データ：`estimate/index.html` + `estimate/assets/js/app.js`（V0.4）
- JSは末尾の `<script>` に内包。価格ロジック、コピー、確定ボタン、PDF、JPEGを保持

## Wixエディタでの手順
1. ページ「見積もりお試し」（URLスラッグ: `estimate-test`）を開く。
2. ページメニューで「メニューから非表示」を選択。さらにSEOページ設定で検索エンジンのインデックスをオフにする（メニュー非表示だけでは非公開にならない）。
3. 「パーツを追加」→「埋め込みコード」→「HTML埋め込み」を追加。
4. パーツの「HTML設定」で「コード」を選択。
5. GitHubの `wix/estimate-test.html` の **Raw表示**を開き、全文をコピーしてコード欄に貼り付け、「適用」を押す。
6. 埋め込みパーツをできるだけ横幅いっぱいに広げ、高さも十分取る。WixのHTML埋め込みはiframeで内部スクロールが発生し得るため、PC/モバイル双方をプレビュー。
7. 試験内容：商品切替、ページ数・部数変更、確定、金額と内訳、PDF、JPEG、LINEリンク、画面の縦スクロール。
8. Wixエディタで「保存」。**「公開」は社長承認後**。すでにページを公開済みの場合はテスト用URLの取り扱いに注意。

## 制限・安全上の注意
- 埋め込みはWix iframe内で動くため、印刷、PDF/JPEG保存、タブを開く動作がブラウザに制限されることがある。実機試験必須。
- 「メニューから非表示」「検索エンジンのインデックスをオフ」は閲覧制限ではない。必要ならページのパスワード保護を設定。
- 外部Google FontsをCSS内で取得する。Norton等のブロックやCSPにより代替フォントになる場合がある。
- **表示価格は仮の試作料金。正式見積書として顧客へ送らない。**
- GitHubのRaw URL自体をWix「ウェブアドレス」に入力するのではなく、「コード」に全文を貼る。こうするとブラウザでgithub.ioのページを取得しない。

## 更新方法
コードの正式管理元は `estimate/`。こちらはWix用の配布版として一度生成したスナップショット。以降の改修はIssue/PRで元コードとWix版の同期を取る。
