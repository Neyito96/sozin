# 複数商品見積もり試作 Ver.0.6.0-multi

Issue: https://github.com/Neyito96/sozin/issues/21

## 目的
1件の見積もりに複数の商品を追加し、各商品の仕様と数量を設定し、すべての条件に対応した公表価格がある場合のみ税込合計を表示する。顧客に単価や内部内訳を表示しない。Wix CMSへ移行する前の**試作**。

## 試作ファイル
- `wix/estimate-multi-test.html`: Wix埋め込み向けの単一HTML、幅780px以下で1カラム
- `pricing/program-price-table.csv`: ユーザー提示の80価格（10数量×8ページ）
- `pricing/PROGRAM_SPEC.md`: 発表会プログラムの紙・印刷仕様

## 操作
- Wixに**新しい試験用ページ**を作成し、「HTML埋め込み」→「コード」に `estimate-multi-test.html` のRaw全文を貼付、適用、プレビュー。
- 既存の「見積もりお試し」Ver.0.5.1は上書きしない。
- 「商品を追加する」で複数行を作成。異なる仕様の同商品を複数回追加できる。
- PDF/JPEGは旧版に存在するが**Ver.0.6の多商品版では未実装**。多商品対応後の追加工程とする。

## 発表会プログラム
- 表紙2案を含むデザイン＋印刷
- A4/B5仕上がり、4P二つ折り・6P三つ折り・8P以上は中綴じ
- 両面4色・本文白黒・コート紙またはマット紙135kg
- 100〜1000部（100刻み）、4/6/8/12/16/20/24/28Pの80通りだけ数値を引く。
- **サイズ/紙種で同じ価格表を使用可能かは社長の最終承認待ち**。現段階は試作の仮適用。
- 表にない組合せは補間しない。

## 他商品
- 公式参考価格に掲示されたデジタルPDF・デジタルブック・セット用データ・ポスター・バナーを選べる。
- ポスター・バナーは原則プログラムとのセット注文・同デザインが前提。カートにプログラムがない場合は合計を未確定とする。
- 紙プログラムの同時選択だけでは「同デザイン」の条件を検証できない。正式見積時に社長が確認。
- チケット・チラシは金額不明のため個別見積もり。**一部に個別見積もりがある場合は部分合計を最終額として表示しない**。

## 技術的制約・今後
- 現在は価格表と計算処理が埋め込みHTML内にあるため、ソースを解析すれば単価情報が読める。**内部単価を完全に秘匿するにはWix Veloバックエンド＋非公開CMSが必要**。
- 社長によるCMS編集（商品、仕様、数量、料金、適用条件、公開設定）はIssue #19で実装。
- 公式価格と税込/送料条件は管理者が公開前に検算する。
- WixのPC/モバイルプレビューとPDF/JPEG代替手段を検証後、本番公開は社長承認で判断。
